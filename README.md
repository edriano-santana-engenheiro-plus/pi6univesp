# IntegraSoft Delivery

Sistema de delivery com painel web e apps Android (cliente e motoboy).

## Stack

- PHP / MySQL
- Android (Kotlin)

## Configuração

1. Copie `.env.example` para `.env` (se existir) e configure o banco.
2. Instale dependências PHP/Android conforme o projeto.

## Segurança

Não versionamos `.env`, keystores nem `local.properties`.
